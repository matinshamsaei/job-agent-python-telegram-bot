# Project Instructions

## GitHub

- You may inspect branches, commits, issues and pull requests.
- You may create commits.
- Do not force push.
- Do not delete branches unless explicitly requested.

## Vercel

- You may inspect deployments, logs and environment variables.
- You may deploy when explicitly requested.
- Do not delete production deployments or projects.

## Supabase

- Use migrations for database schema changes.
- Never directly modify production schema unless explicitly requested.
- Never reset the production database.
- Prefer local development and migrations before pushing changes.

## General

- Before destructive operations, ask for confirmation.
- Never expose secrets in commits, logs or responses.
